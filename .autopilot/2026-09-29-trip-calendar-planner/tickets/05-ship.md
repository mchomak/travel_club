# 05 — Выпуск main и запуск Docker

**Требования:** R14, R15
**Blocked by:** 07, 08
**Зона:** `.autopilot/`, `docs/`, Git, Docker Compose
**Волна:** 6
**Status:** ready

## Что должно заработать

После завершения реализации и проверок результат сохранён в истории, отправлен в `origin/main`, Compose пересобран и запущен с миграцией и доступными frontend/API. Этот таск завершается при финальной приёмке; пользователь уже явно разрешил push и перезапуск.

## Из брифа, дословно

> «сделай коммит пуш в main ветку затем пересобери docker и запусти»

## Разделы спецификации

Истории 24–25, открытые места R14.

## Критерии приёмки

- [ ] Проверки реализации пройдены; нет секретов, временных файлов и случайного удаления пользовательских данных.
- [ ] Коммит со всеми относящимися к задаче изменениями существует, локальная и удалённая `main` указывают на него; история не переписана.
- [ ] После push выполнены `docker compose build` и `docker compose up -d --wait`; миграция применена, сервисы healthy.
- [ ] HTTP проверка frontend и API подтверждает запуск; финальный отчёт содержит commit, состояние Docker и результаты проверок.
