==================================================
1. ГЛАВНАЯ ИДЕЯ НОВОЙ АНИМАЦИИ
==================================================

Сейчас механика концептуально выглядит примерно так:

закрытый журнал
→ журнал открывается
→ пользователь видит разворот
→ журнал немного увеличивается
→ отдельно начинается сайт.

Нужно изменить саму концепцию перехода.

НОВАЯ ЛОГИКА:

закрытый журнал
→ журнал открывается
→ появляется разворот
→ пользователь начинает приближаться к ПРАВОЙ странице
→ правая страница становится всё больше
→ левая страница и корешок уходят за пределы viewport
→ исчезает ощущение физического журнала
→ правая страница занимает весь экран
→ её композиция естественно превращается в настоящий homepage

Ключевой эффект:

THE PAGE BECOMES THE WEBSITE.

Пользователь не должен ощущать:

"анимация закончилась → загрузился следующий блок".

Он должен ощущать:

"я открыл журнал → вошёл внутрь страницы → эта страница и есть сайт".

==================================================
4. SCROLL JOURNEY
==================================================

Весь opening должен занимать ориентировочно:

1–1.5 viewport scroll journey.

Не растягивай интро на 3–5 экранов.

Ориентировочные фазы:

0–20%
COVER

20–45%
OPENING

45–75%
FOCUS ON RIGHT PAGE

75–100%
MERGE INTO WEBSITE

Это не жёсткие цифры.
Настрой их после визуального теста.

Главное — ритм:

быстро понять объект
→ открыть
→ увидеть spread
→ войти внутрь
→ сайт.

==================================================
6. PHASE 2 — OPENING
==================================================

При scroll журнал раскрывается.

Должен появиться полноценный spread:

LEFT PAGE
+
RIGHT PAGE

Сохрани общую механику текущего раскрытия, если она работает.

Но animation architecture нужно подготовить к дальнейшему zoom/focus.

Важно:

- opening должен быть плавным;
- perspective должна быть subtle;
- никакой чрезмерной 3D-деформации;
- страницы должны ощущаться как digital editorial object, а не настоящий картон;
- shadows постепенно должны становиться слабее по мере перехода к сайту.

==================================================
7. PHASE 3 — FOCUS
==================================================

После открытия начинается новая часть.

Камера / visual frame начинает смещаться к ПРАВОЙ странице.

Одновременно:

- весь spread увеличивается;
- центр масштабирования смещается к правой странице;
- правая страница становится визуально доминирующей;
- левая страница постепенно выходит за левую границу viewport;
- центральный сгиб / spine также уходит влево;
- фон вокруг журнала становится всё менее заметным;
- box-shadow уменьшается;
- perspective выравнивается.

Очень важно:

не делай просто:

transform: scale(3)

по центру spread.

Нужно ощущение направленного camera movement:

ZOOM + TRANSLATE + LOSS OF OBJECT BOUNDARIES.

==================================================
8. PHASE 4 — MERGE
==================================================

Это главный момент анимации.

ПРАВАЯ страница должна постепенно перестать восприниматься как отдельный лист.

Для этого:

- её внешние края уходят за viewport;
- shadow становится 0;
- perspective становится 0;
- page background становится background сайта;
- её внутренний editorial grid начинает совпадать с grid homepage;
- элементы страницы могут немного reposition/resize, если это необходимо для совпадения с hero.

В финальной точке:

нет визуальной границы между:

"right magazine page"

и

"homepage".

Пользователь должен оказаться внутри сайта без заметного переключения сцены.
