# Эталон

На что это должно быть похоже. Собрано только из приложенных пользователем скриншотов.

## Внешний вид
- Скриншот 1 из брифа: у формы перелёта есть секция «Вылет» с рядом полей «Вылет — страна» и «Вылет — город»; у поля страны плейсхолдер «Найдите страну», у города виден выбранный «Moscow».
- Скриншот 2 из брифа: текстовое поле «Маршрут / аэропорты» с примером «Например, Москва — Стамбул»; пользователь просит убрать это поле.
