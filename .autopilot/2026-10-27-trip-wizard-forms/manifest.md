## Самобрифинг — full

- **ASSUMPTION (R01–R04, R08–R11):** на шаге 2 встроенная форма меняется только для перелётов; другие дальние переезды/поезда/автобусы сохраняют прежний способ редактирования. На шаге 3 встроенная форма применяется к проживанию. Используется тот же TripEditor/DraftSession. Формы открываются под строкой элемента на странице; черновик становится элементом поездки только после сохранения, отмена отбрасывает несохранённый ввод. Календарь остаётся полной проекцией тех же данных под анкетой.
- **ASSUMPTION (R02–R03, R09–R10):** существующие редактирование, удаление, перенос, поля расчёта и заметки сохраняются; добавление нового элемента в анкете открывает его встроенную форму. Одновременно редактируется один элемент, чтобы не терять несохранённые данные.
- **ASSUMPTION (R05):** каждый вариант города, который пользователь может выбрать из результатов поиска или истории, имеет ISO-код; выбор атомарно задаёт город и страну. Если поисковик не вернул код, такой результат не становится подтверждённым вариантом. Свободный текст требует ручного выбора страны.
- **ASSUMPTION (R06):** подсказки истории ограничены текущей поездкой и берутся из страны/города отправления и прибытия уже добавленных перелётов; повторы объединяются, новые данные отдельно не сохраняются.
- **ASSUMPTION (R07):** убирается только текстовое поле «Маршрут / аэропорты» у перелёта. Исторические значения и модель `location` не удаляются из сохранённых поездок; отдельные поля выбора места для карты сохраняют свою работу.
- **ASSUMPTION (R12–R14):** карандаш дня из полного редактора сначала сохраняет текущий черновик и открывает существующий builder на шаге 4 с выбранным днём. При ошибке сохранения пользователь остаётся на исходном экране.
- **ASSUMPTION (R15):** «основная ветка» означает `origin/master`, на которую указывает `origin/HEAD` в текущем checkout. Перед push сверю актуальное состояние удалённой ветки; чужой незакоммиченный DOCX исключу из коммита.
- Пользовательских фактов и секретов для полей этой правки не требуется; placeholders не нужны.
