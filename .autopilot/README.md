# Как читать эту папку

`dashboard.html` — живой прогресс сборки. `state.js` хранит состояние для продолжения.
В папке прогона: исходный бриф, требования, спецификация, границы модулей и таски.
Суффикс `--wip` означает, что работа ещё не принята. Для продолжения скажи «продолжи автопилот».
