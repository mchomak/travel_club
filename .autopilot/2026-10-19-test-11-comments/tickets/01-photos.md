# 01 — Две фотографии для новой композиции

Зона: frontend/public/test_11/ только. Требования R01, R10, связанные R02/R03. Спецификация: Hero и Thailand.

Цитаты: «найди другую картинку… справа была гора, а слева чистое небо»; «другое изображение, чтобы надпись Thailand не сливалась с зеленым фоном».

Найти реальные лицензированные фотографии (предпочтительно Pexels/Unsplash/Wikimedia), проверить source/author/license через web. Hero — гора справа, много чистого светлого неба слева (готовим композицию с туманом и лого). Thailand — светлая тайская сцена, минимум тёмно-зелёного, чтобы фото в буквенной маске читалось на тёмно-зелёном фоне. Сохранить два локальных WebP, в пределах ~1800px, обновить manifest.json и README источниками, authors, размерами, лицензией. Используй существующий sharp из frontend/node_modules для конвертации. Не менять код/data/CSS, старые assets не удалять и не заменять.

Проверь визуально оба файла через view_image; вернуть имена, alt, author. Если нет точного hero, искать дальше; не генерировать изображение без причины. Без git действий.
