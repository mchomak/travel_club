# 05 — Приёмка и документация
**Требования:** R01–R267, G01–G03.
**Зона:** docs, README, приёмочные тесты, точечные исправления после ревью.
**Волна:** 3; **Blocked by:** 04

> «Не считай успешное перемещение файлов достаточным результатом»
> «Не выдавай непроверенную функциональность за рабочую»

Выполнить проверки из раздела spec.md «Детали исполнения и приёмки»: отдельные lint/typecheck/build, маршруты, CTA, браузерные ошибки, формы, адаптивность, реальные сценарии поездок/карты/календаря и интервью/ответов/версий/API/БД, изоляцию CSS через временную смену токенов с восстановлением. Обновить корневой и три app README, архитектуру и архив, зафиксировать команды, реальные ограничения, Release и результаты. Не представлять недоступные проверки пройденными.

Приёмка: результат всех команд и сценариев с доказательствами; сохранённые данные и общая сессия; документация соответствует реализации; полный список ограничений.
