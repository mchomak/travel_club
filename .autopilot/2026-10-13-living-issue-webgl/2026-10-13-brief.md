\==================================================\
7\. ГЛАВНОЕ ТРЕБОВАНИЕ — REAL PAGE CURL\
\==================================================\
\
НЕ делать перелистывание как:\
\
flat plane\
\+\
rotateY(180deg).\
\
Это не принимается.\
\
Страница должна реально менять форму.\
\
Во время flip:\
\
\- область возле spine остаётся ограниченной;\
\- свободный край поднимается;\
\- по странице проходит bend / curl;\
\- поверхность становится кривой;\
\- изгиб меняется во времени;\
\- после перелистывания страница снова становится почти плоской.\
\
Схематично:\
\
FLAT\
\
───────────────\
\
\
EARLY FLIP\
\
───────╮\
&#x20;      ╰────\
\
\
MID FLIP\
\
────╮\
&#x20;   ╰─────╮\
&#x20;         ╰─\
\
\
FINAL\
\
───────────────\
\
Используй subdivided plane geometry.\
\
Количество subdivisions должно быть достаточным для плавного curvature.\
\
Ориентир:\
примерно 32–64 сегмента по ширине страницы.\
\
Не считай это жёстким значением:\
подбери оптимум визуально и по performance.\

\==================================================\
9\. PAGE MOTION MODEL\
\==================================================\
\
Flip должен ощущаться примерно следующим образом.\
\
0–15%\
\
страница начинает подниматься за внешний край.\
\
15–40%\
\
формируется основной curl.\
\
40–65%\
\
страница проходит через наиболее сильный изгиб.\
\
65–90%\
\
она начинает раскрываться на противоположную сторону.\
\
90–100%\
\
curvature уменьшается и лист мягко ложится.\
\
Не делать:\
\
constant-speed rotate.\
\
Motion должен содержать:\
\
acceleration\
→ main movement\
→ deceleration.\
\
Без bounce.\
Без elastic spring.\
Без cartoon overshoot.\

\==================================================\
10\. SPINE\
\==================================================\
\
Особое внимание spine.\
\
Страница не должна выглядеть так, будто вся плоскость вращается вокруг центра.\
\
Корешок должен давать визуальное ощущение физического ограничения.\
\
Near-spine vertices:\
\
\- двигаются заметно меньше;\
\- остаются anchored;\
\- создают начало bend.\
\
Outer edge:\
\
\- имеет максимальный displacement;\
\- описывает основное движение страницы.\
