# Спецификация: Living Issue /test_7

## Задача и решение
Отдельная страница соединяет физическое перелистывание лаборатории с живой редакционной homepage. Сначала автопоказ обложки и восьми листов из JSON; затем пользователь сам приближает финальную правую страницу прокруткой. Она уже является настоящим сайтом /test_5, остаётся тем же DOM и становится обычным документом.

## Решения по реализации
- Direct Three.js и нынешняя геометрия/свет лаборатории; никакой новой dependency. Локальная изолированная адаптация сцены, чтобы контрольная лаборатория сохранилась.
- Корневой JSON — эталон. Для автономного Docker context frontend допустим точный снимок внутри новой версии; проверка сравнивает settings с корнем. Не менять числа preset.
- Одна живая homepage /test_5 переиспользуется чтением существующих компонентов; provider сохраняет редактор фото. Не клонировать все site components без необходимости.
- Живой DOM рисуется под прозрачным WebGL canvas и projective matrix3d совмещает его с четырьмя проекциями финальной правой страницы. Depth-tested прозрачная маска стирает правую страницу/стек в canvas; curl остаётся сверху и физически перекрывает живую поверхность. Отдельный shadow receiver над маской сохраняет тень перелистывающейся бумаги. Никакой screenshot-заглушки вместо homepage.
- На последнем flip под листом уже настоящий website. Camera focus приближает этот же plane, постепенно делает взгляд фронтальным и выравнивает верхний левый край с viewport. На конце её проектирующая матрица становится единичной; живой DOM выходит в обычный flow без crossfade/remount.
- READY/FOCUS/SITE — deterministic scroll model, расстояние около1.25 viewport heights. Изменения scroll passive; кадры только при движении; измерения через ResizeObserver и resize/fonts, а не внутри scroll frame. Intro блокирует scroll с восстановлением предыдущих body/html стилей при выходе/unmount/fallback. Обратный scroll действует после TARGET и не сбрасывает sequence.
- Чистая сцена без панели лаборатории; небольшой бренд/skip/подсказка. Никаких оплат/серверных изменений или новых продуктов.

## Границы и швы
Вся feature — один связный исполнитель; публичная граница с сайтом — React children, ровно один EditorialHome. SceneController управляет clock/focus/dispose; DOM coordinator управляет lock/native flow/hash и принимает projected page quad из сцены. Математика camera/projection скрыта внутри новой версии; тестовый шов — DOM scene datasets (phase/focus/frames) и доступные UI/настоящий scroll. Root preset equality и projective corners допускают небольшие pure checks, без зеркалирования внутренностей.

## Проверки
Lint/typecheck, существующие unit tests, production Docker build, целевые browser сценарии intro→final→zoom→native flow→reverse, ранний wheel, skip/hash, reduced motion, resize и отсутствие WebGL; контрольные /test_5 и /test_6 regression. Визуально сравнить midcurl и края DOM/WebGL на финале,25/50/75% приближения. Тестовые артефакты вне production route. Подтвердить git scope/push.

## Вне рамок и открытые места
Ничего из брифа не отложено. Существующие демонстрационные формы и иллюстративные фотографии сохраняют нынешний статус. Известные унаследованные Next CSS preload warnings не требуют изменения общих routes. Сохраняется текущая локальная модель photo editor /test_5 при повторном использовании provider.
