# Границы и правила сборки

## Границы, решённые в спецификации

- `TripCalendar` владеет заголовками дней, сводкой событий и цен, кнопкой редактирования дня и высотой прокручиваемой сетки. Проверяемый шов — компонент `TripCalendar` и существующие тесты этого компонента.
- `TripEditor` остаётся владельцем формы дня и обработчика её открытия; контракт не меняется. Новых модулей, API и зависимостей нет.

## Контекст проекта

- Это небольшая правка одного экрана календаря администратора (T0); задачами работа не разбивается.
- Проект: Next.js 16.3.6, React 19.3.0, TypeScript 6.0.3. Использовать существующие зависимости и стиль компонентов.
- Не менять модель поездки, API, сохранение и расчёт цен. Не удалять счётчик и сумму дня.
- Сохранить доступность кнопки и работу календаря на планшете; полный день остаётся доступен внутренней прокруткой.
- Если для правки якобы не хватает пакета или другого внешнего ресурса, вернуть `BLOCKED` с причиной; не устанавливать его.

## Проверки

Из каталога `frontend`:

- Целевой тест: `npm.cmd test -- src/components/trips/trip-calendar.test.tsx`
- Общие проверки: `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd run build`
- Браузерная проверка: `npm.cmd run test:e2e -- e2e/constructor.spec.ts` при запущенном Compose на `localhost:3000`.

## Реализация этого прогона

- Шапка дня теперь содержит отдельную кнопку-иконку `Pencil` рядом с датой; она вызывает прежний `onEditDay`, не нажимая кнопку выбора даты. Текстовая кнопка удалена. Размер нажатия — 44×44 px.
- Из заголовка удалены `<details>` и поясняющий текст; число событий и стоимость дня остаются на месте.
- Прокручиваемая область ограничена `90vh` с минимальной высотой `740px`. На окнах 768px и 900px она выше 720px; все 24 часа доступны внутренней прокруткой.
- Unit-тесты `TripCalendar` проверяют эти границы и отсутствие пояснения; браузерные сценарии для экрана конструктора и планшета проходят.

## Ticket 01 — итоговый контракт

- `TripCalendar` сохраняет прежние props и ограничивает внутреннюю область календаря `maxHeight: 90vh`, `minHeight: 740px`, `overflowY: auto`.
- Конструкторский Playwright-сценарий проверяет высоты окна 900px и 768px, рост области относительно 720px и доступность отметки 23:00 после внутренней прокрутки.
- Тесты: компонентный `trip-calendar.test.tsx` — 13 passed; отдельный Playwright-проверочный сценарий — 1 passed.
