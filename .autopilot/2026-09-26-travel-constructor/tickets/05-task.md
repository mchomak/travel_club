## Что должно заработать

Закрыть два замечания независимого Craft review после T04, не меняя бизнес-логику. Тест выхода из учётной записи не должен отзывать общую сессию, которой пользуются другие тесты того же набора. Повторное создание фикстур после logout должно оставаться возможным независимо от порядка тестов. В README и матрице приёмки точно описать изоляцию тестов: обычные backend-транзакции откатываются, а конкурентные проверки с commit выполняются в собственных временных PostgreSQL-схемах с последующей очисткой. Не утверждать, что каждый тест откатывает транзакцию.

## Критерии приёмки

- [ ] Logout-сценарий создаёт или использует изолированную сессию; общая `authCookies` для остальных Playwright сценариев остаётся действительной.
- [ ] Набор Playwright проходит после logout и при повторе (`--repeat-each=2` или эквивалентная проверка) без 401 из-за общей сессии.
- [ ] README и `docs/acceptance.md` описывают оба механизма тестовой изоляции без ложного утверждения о rollback каждого теста.
- [ ] Соответствующие frontend checks и `git diff --check` проходят; никакие реальные пользовательские записи не затронуты.
