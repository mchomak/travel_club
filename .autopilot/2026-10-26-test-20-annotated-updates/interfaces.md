# Границы реализации — `/test_20`

**Проект:** Next.js 16, React 19, TypeScript, CSS Modules; без новых зависимостей.

## Владение

- `ConceptHome` владеет разметкой страницы, контентом блоков и ссылками карточек. Карточки услуг ведут на существующие hash-якоря `/formats`; нижний CTA остаётся общим переходом к разговору.
- `design-tokens.ts` владеет палитрой стандартного режима и связью секций с цветами. Настройки `/test_20` остаются локальными и не влияют на другие страницы.
- `concept.module.css` владеет композицией и адаптивными стилями, включая карточки, навигацию, NEXT ISSUE, вставку FIELD NOTES и фото-полосу China.
- `BrandLogo` выбирает уже существующий вариант фирменного SVG для тёмной навигации и сохраняет прежние варианты в hero/footer.
- `photo-slots.ts` остаётся владельцем стабильных фото-ID, fallback, alt и crop. Используются существующие ID, новые общие assets не создаются.
- `/formats` — назначение ссылок и read-only поверхность; в рамках работы его содержимое не меняется.

## Проверочная граница

Визуальные и поведенческие проверки идут через `frontend/e2e/test-20-home.spec.ts` и `frontend/e2e/test-20-settings.spec.ts`. Общая дизайн-система и другие страницы не входят в область изменений, кроме необходимой регрессии изолированности.

## Ограничения для исполнителя

- Не менять пользовательские незакоммиченные файлы за пределами `test_20` и его существующих проверок.
- Не менять публичный каталог услуг или общие токены дизайн-системы.
- Не выполнять перевод страницы, сетевые запросы, установку зависимостей или изменения backend.
- Перед изменениями проверить `git status`; существующие untracked файлы `/test_20` уже были в рабочей копии.

## Команды проверки

Из `frontend/`: `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd test -- --run --testTimeout=15000`, `npm.cmd run build` и целевые Playwright `e2e/test-20-home.spec.ts e2e/test-20-settings.spec.ts`. Production preview запускать по инструкции проекта, если доступен.

## Границы, решённые в спецификации — дополнение от 28 октября

- `ConceptHome` остаётся владельцем композиции. В заголовке формата появляется отдельная группа номера и английского названия; в Thailand-графике разделяются год и подпись, чтобы переместить только `’26`; заметка NEXT ISSUE остаётся отдельным элементом.
- `concept.module.css` оформляет подложку, локальное оформление заметки, цвет иконки, позицию года и слой узора.
- Новый SVG-ресурс используется только как повторяемый декоративный фон секции China. Он не заменяет существующий фон и не содержит содержимого, доступного для взаимодействия или чтения с экрана.
- Проверочная граница остаётся существующим `frontend/e2e/test-20-home.spec.ts`; настройки темы и `/test_13` не изменяются.
- Изменения не затрагивают общие токены, `/formats`, фото-слоты, маршруты, backend или пользовательские незакоммиченные файлы.
- Для локальной проверки доступны команды из `frontend/`: `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd test -- --run --testTimeout=15000` и `npm.cmd run build`. Для production preview проект использует `docker compose up -d --no-deps --build --wait frontend` из корня.
