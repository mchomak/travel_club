# Спецификация: визуальные правки `/test_20` по шести скриншотам

## Задача

На странице `/test_20` нужно внести шесть локальных правок по присланным скриншотам. Это продолжение уже готовой страницы: сохраняются её тексты, секции, палитра, изображения, редактор фотографий и адаптивное поведение. Для подписи NEXT ISSUE отдельно задано ограничение: менять только её.

## Решение

1. В карточках услуг появляется светлая подложка только под номером и английским названием; ссылка «Подробнее» остаётся отдельно.
2. Заметка NEXT ISSUE в левой нижней части постера показывает текст «Ещё не на карте. Уже в планах.» в две строки с засечками, как в референсе. Старая плашка «Первое групповое / в подготовке» убирается; остальные тексты и элементы NEXT ISSUE не меняются.
3. Иконка рядом с FIELD NOTES получает красный цвет из палитры `/test_13`.
4. Год `’26` перемещается в верхнюю правую часть графики THAILAND. Подпись «Таиланд в двух ритмах» остаётся у нижнего левого края.
5. Фон секции CHINA получает неброский повторяющийся орнамент по мотиву присланного китайского узора.
6. Завершённый код и запись прогона коммитятся и отправляются в default-ветку `master` (`origin/HEAD`).

## Решения по реализации

- Страница остаётся локальным React-компонентом `/test_20`; новые серверные API и зависимости не нужны.
- Подложка оформляется внутри заголовочной группы формата и строится от текущего цвета поверхности секции, чтобы работать с существующими настройками темы.
- Текст заметки сверяется с исходником `/test_13`; меняются только её собственные разметка и стили.
- Иконка получает отдельный локальный override цвета `#CE3C28`, чтобы не перекрашивать другие символы или общий токен палитры.
- Год и нижняя подпись в Thailand разделяются на два локально позиционируемых элемента; это позволяет переместить только год.
- Орнамент — локальный повторяемый SVG-фон без внешнего изображения и сетевого запроса. Его слой не перехватывает ввод и не участвует в чтении с экрана.
- Пользовательский запрос «основная ветка» трактуется по Git-метаданным проекта: `origin/HEAD` указывает на `master`, а отдельная `main` не является default и отстаёт на шесть коммитов.

## Границы и швы

Один шов: локальная композиция `/test_20` и её CSS-модуль. Компонент отвечает за расположение элементов, CSS — за их поверхности и позиции; декоративный SVG используется только как фоновый ресурс секции China. Остальные страницы и общие токены проекта не меняются.

## Вне рамок

- `/test_13` остаётся неизменным и служит источником точной подписи и локального визуального образца.
- Не меняются другие надписи, положение секций, фото, цены, навигация, формы и редактор изображений.
- Не добавляются новые сведения о поездках, внешние изображения, библиотеки или поведение сайта.
