## Решения полного автомата

- ASSUMPTION — публичная ссылка строится из IP `31.57.143.12`, ранее указанного пользователем для SSH, и первого свободного/доступного HTTPS порта (8443, затем 9443/10443); порт 80/tcp нужен для ACME HTTP-01, автоматическое продление короткоживущего сертификата обязательно.
- ASSUMPTION — создать отдельный проект Compose и отдельный volume PostgreSQL в `/opt/travel_club`; существующую БД паспортного бота и контейнеры не подключать и не менять.
- ASSUMPTION — публичные редакционные страницы доступны без входа; маршруты конструктора и API остаются под существующей серверной cookie-аутентификацией; открытая регистрация не добавляется.
- ASSUMPTION — сайт будет использоваться как демонстрация с небольшой нагрузкой; локальная сборка frontend снижает пик потребления памяти на VPS с 2 ГБ RAM.
- ASSUMPTION — проверочные пороги 300 MiB свободной RAM и 3 GiB диска после запуска защищают малый VPS; ожидаемая конкурентность и нагрузка от пользователя не заданы.
- ASSUMPTION — логин первого администратора `traveladmin`, уникальный случайный пароль; пароль выводится только пользователю в запрошенном чате.
- ASSUMPTION — деплой разрешён только после успешного push commit в `origin/main`; в commit входят все текущие изменения рабочего дерева, кроме env-секретов и машинных файлов, которые уже игнорируются.
