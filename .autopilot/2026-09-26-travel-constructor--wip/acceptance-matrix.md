## Неблагоприятные сценарии

- Потеря сети при save: поля остаются, нет ложного «Сохранено», повтор успешен.
- Более свежая версия из другой вкладки: 409 без перезаписи.
- Shrink заполненных дат: отказ без подтверждения; cancel сохраняет содержимое; отдельное подтверждение разрешает удаление.
- Отель вне диапазона: явная ошибка, нет скрытого сокращения ночей.
- Не задан курс, capacity=0, target_margin=100, отрицательное/NaN: понятный отказ, нет ложного итога.
- Выключенный included: видим в маршруте, не влияет на общую стоимость.
- mode=hotel у type=other распределён по ночам; type=hotel/manual в один день/общие расходы.
- Ночное перемещение 23:00–02:00 сохраняет оба времени с отметкой следующего дня.
- Preview показывает client notes trip/day/item, скрывает все internal notes.
- Mobile 390px: диалоги, поля и действия доступны, горизонтального overflow нет.

## Инструменты процесса

На Windows стандартный Autopilot sync.py пытается вызвать POSIX ps. Применяется `python -X utf8 .autopilot/sync.py --no-serve`; HTTP server запущен скрыто на 127.0.0.1:8765. index.html — hardlink на dashboard.html, так как Windows symlink может требовать привилегий. Это адаптация процесса, не изменение продукта.
