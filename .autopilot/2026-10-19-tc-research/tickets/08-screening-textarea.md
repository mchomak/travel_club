# Ticket 08 — Поддержка textarea из JSON

## Требования

R17 — учесть вопрос о трудностях подготовки поездки.
R18 — типы вопросов и варианты ответов задаются JSON без исправления интерфейса вручную.

## Найденный дефект

В screening.json одно поле задаёт control: "textarea", однако форма для всех неизвестных типов рисует select без вариантов. Интервьюер не может записать ответ в это поле.

## Сделать

Добавить `textarea` в тип `ScreeningField` в `frontend/src/lib/research.ts` и использовать типизированную ветку в `frontend/src/components/research/screening-form.tsx`, когда control из JSON равен textarea. Не привязывать поведение к коду вопроса или конкретному ключу. Сохранить label, текущий ответ, required/optional поведение и обработчик изменения. Добавить тест к `screening-form.test.tsx`, который берёт поле с textarea control из конфигурации и проверяет ввод/сохранение значения.

## Проверка

- Новый тест красный до исправления и проходит после.
- Существующие тесты screening-form.test.tsx проходят.
- Не меняются JSON, классификация и backend.
- git diff --check проходит.
- Изменены только тип поля, форма анкеты и её тест.
