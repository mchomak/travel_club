## Что должно работать

Защищённый backend создаёт респондента и draft-интервью атомарно, фиксирует категории и snapshot сценария, хранит ответы, безопасно меняет их с CAS, фильтрует записи, завершает интервью и выгружает всю базу в открываемый Excel. API не доверяет входящему вопросу и работает только по вопросу в snapshot.

## Из брифа, дословно

> «PostgreSQL — для постоянного хранения данных»
> «Используй отдельные таблицы с префиксом `research_`»
> «Уникальность ответа по паре `interview_id + question_code`»
> «Важно сохранять snapshot вопросов внутри интервью»
> «Не показывать “Сохранено”, пока сервер не подтвердил запись в PostgreSQL»

## Критерии приёмки

- [ ] Аддитивная Alembic-миграция создаёт три `research_` таблицы с UUID/FK/JSONB/TEXT/checks/indexes, уникальным ответом и целой revision. Интервью допускают исторические записи; изменение анкеты не затирает ответы.
- [ ] Все API-запросы защищены текущей admin-сессией и CSRF. Проверка CSRF принимает `ALLOWED_ORIGIN` и настроенный `RESEARCH_ORIGIN`; пустой `RESEARCH_ORIGIN` сохраняет прежнее поведение. Можно создать запись до интервью, получить recommendation, изменить final category/override, запустить snapshot, добавить вопросы, пересчитать recommendation без смены начатого маршрута, получить список/карточку.
- [ ] `PUT answer` принимает expected revision, обновляет ответ атомарно/идемпотентно; устаревшая revision получает 409 с актуальным значением и не затирает PostgreSQL. Отвечать можно после completed; `updated_at` меняется, статус остаётся `completed`.
- [ ] Старт и завершение транзакционны; завершение разрешено с пустыми ответами и сохраняет `completed_at`. Повторные запросы не создают повторных ответов.
- [ ] Список поддерживает поиск, категории/статусы, сортировку дат, pagination и общие/completed/incomplete счётчики. API возвращает понятные ошибки без стека.
- [ ] Auth, create/rollback, классификация, override, snapshot после изменения JSON, доп. вопрос, CAS гонка/повтор, пустой completion, поздняя правка, filters/counts и отсутствие доступа покрыты pytest.
- [ ] Авторизованный полный `.xlsx` имеет пять листов, включает все строки включая пустые, screening-столбцы и гипотезы; русский, переносы, длинный ответ split-в-колонки, formula-looking текст остается текстом. Экспорт повторно отражает обновления. Добавлена только закреплённая зависимость `openpyxl==3.1.5`.
