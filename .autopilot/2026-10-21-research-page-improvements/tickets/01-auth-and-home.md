## Что должен сделать исполнитель

После входа вернуть пользователя на тот защищённый адрес, который он изначально запросил, включая query string. Небезопасные и внешние return URL отбрасывать. Если пользователь вошёл без исходной страницы, показывать защищённую /home.

Создать /home как каталог существующих страниц проекта: разбить ссылки на понятные тематические группы и для каждой дать краткое описание. Каталог должен проверять сессию на сервере. Не редактировать страницы /test_12 и /test_13 или worktree другой сессии; указать для них относительные ссылки и пометить «В параллельной сборке».

## Решения спецификации

См. .autopilot/2026-10-21-research-page-improvements--wip/spec.md, разделы 1–2. Сохранять только безопасный same-origin path + query; fallback — /home. Каталог группирует существующие маршруты проекта, включая /admin/login; динамические страницы доступны через списки. Для test12/test13 канонические ссылки /test_12 и /test_13, пока помеченные как доступные в параллельной сборке.
