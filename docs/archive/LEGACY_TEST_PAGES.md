Исходный код экспериментов сохранён в локальном аннотированном Git-теге `archive/legacy-test-pages-01-19`, созданном до удаления файлов. ## Перекрёстные зависимости перед очисткой

Эта таблица фиксирует перекрёстные зависимости в сохранённом pre-cleanup снимке. Legacy cleanup завершён: 620 tracked файлов `frontend/` и два скрипта `test9` удалены из активной структуры; ignored/untracked локальные данные оставлены нетронутыми. Экспериментальные маршруты не входят в активные app routes. Исторические пути и связи сохранены для адресного восстановления из тега; не трактуйте их как текущие импорты.

## Просмотр и восстановление

Проверить содержимое сохранённого файла, не меняя рабочее дерево:

```powershell
git show archive/legacy-test-pages-01-19:frontend/src/app/test_20/page.tsx
```

Для полноценного просмотра архивной версии в отдельной папке:

```powershell
git worktree add ..\travel-club-legacy archive/legacy-test-pages-01-19
```

Если конкретный файл позже будет удалён, восстановить его из тега можно адресно. Перед восстановлением проверьте локальные изменения того же пути через `git diff`:

```powershell
git restore --source=archive/legacy-test-pages-01-19 -- frontend/src/app/test_20/page.tsx
```

Удаление временной worktree после просмотра выполняется только для явно созданной папки `..\travel-club-legacy` командой `git worktree remove ..\travel-club-legacy`.

## Архивный тег и Release

[LEGACY_RELEASE.md](LEGACY_RELEASE.md) содержит описание и статус архивной точки. Тег остаётся локальным и не должен отправляться на GitHub; Release не создан, поскольку архивная точка содержит закрытые CustDev материалы. Пути `frontend/...` в этом документе относятся к содержимому тега, а не к активному исходному дереву. Перед восстановлением просмотрите `git status` и diff адресного пути, чтобы не заменить нужные локальные изменения.
