# Карта конструктора поездок: согласованные требования

Дата: 16 октября 2026. Источник: решения пользователя в текущем обсуждении. Это согласованный scope для следующей реализации; код приложения пока не менялся.

## Провайдер и объём

- География — весь мир.
- После затруднений с Google Cloud выбран кандидат на проверку — Geoapify без привязки банковской карты. Перед интеграцией проверить поиск, автомобильный/пеший маршруты и качество общественного транспорта на реальных направлениях; в местах без официальных GTFS-данных время будет приблизительным.
- Ориентир нагрузки — 10–15 поездок в месяц.
- Google Cloud больше не является выбранным путём. Geoapify предлагает бесплатный план без карты; детали лимитов и альтернатив сохранены в [исследовании вариантов без карты](2026-10-17-maps-without-payment-card.md).
- Значения API-ключей и платёжные данные в чат не запрашивать. Для live-проверки потребуется отдельный API-ключ Geoapify, который владелец проекта сохранит локально.

## Карта выбранного дня

- Пользователь выбирает день в календаре; под календарём отображается карта этого дня.
- На карте отмечены события, начало и окончание дня; между соседними точками показывается настоящий рассчитанный маршрут.
- Под картой перечислены участки: «Точка A → точка Б», расстояние и время.
- Для каждого участка одновременно доступны результаты трёх способов передвижения: автомобиль, пешком, общественный транспорт.
- Способ передвижения выбирается отдельно для каждого участка. Этот выбор определяет линию участка на карте и суммарные расстояние/время дня.

## Указание места

- Поиск по названию места или адресу.
- Вставка ссылки Google Maps.
- Возможность уточнить точку на карте.

## Начало дня

- По умолчанию — отель, где путешественники ночевали.
- После ночного перелёта или поезда — аэропорт или станция прибытия.
- После другого ночного события — место его окончания.
- При неоднозначности система просит выбрать подходящий вариант.
- Интерфейс объясняет, почему предложена начальная точка; её можно вручную переопределить.

## Окончание дня

- По умолчанию — отель следующей ночёвки, в том числе новый отель при переезде.
- При ночном отправлении — аэропорт или станция отправления.
- Конечную точку можно вручную переопределить.

## Порядок событий

- Маршрут следует хронологии календаря.
- События со временем идут по времени.
- Для событий без времени используется ручной порядок.
- Автоматической оптимизации и перестановки остановок нет.
