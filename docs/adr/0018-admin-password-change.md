## Контекст
Начальные учётные данные выдаются администратору, которому нужно самостоятельно заменить пароль. Принудительный reset при первом входе исключён из объёма: штатный bootstrap не поддерживает этот режим.

## Решение
Предоставить смену пароля в закрытом кабинете: запрос требует текущий пароль и новый пароль длиной 12–1024 знака. При успешном изменении текущая сессия сохраняется, остальные сессии пользователя завершаются; обновление выполняется транзакционно.

## Почему
Администратор может заменить начальный пароль без ручного редактирования базы, а проверка текущего пароля подтверждает владение активной учётной записью.

## Последствия
Смена пароля становится частью API и страницы аккаунта и должна соблюдать существующую CSRF-защиту. Ошибка базы не должна приводить к частичной смене учётных данных.
