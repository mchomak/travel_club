# ADR 0036 — Не публиковать архивный тег с материалами CustDev

## Контекст

Для сохранения экспериментов создан аннотированный тег `archive/legacy-test-pages-01-19`, указывающий на исходный коммит до реорганизации. При проверке содержимого этого коммита обнаружены внутренние материалы CustDev. Пользователь прямо запретил публиковать их. Одного публичного текста Release недостаточно, чтобы сделать сам commit безопасным. Основание: R30–R46, G03.

## Решение

Хранить архивный тег только в локальной истории разработки и не отправлять этот тег на GitHub; GitHub Release для него не создавать. Черновое описание Release может оставаться документацией, но не является разрешением на публикацию.

## Почему

GitHub Release, связанный с этим тегом, раскрыл бы доступ к содержащимся в target commit файлам, включая внутренние материалы. Обезличенный текст описания не меняет доступность содержимого коммита.

## Последствия

Архив остаётся доступен из локального Git-тега и истории репозитория. Если в будущем потребуется публичная точка восстановления, сначала нужна отдельная очищенная архивная ревизия без CustDev и приватных данных, затем повторная проверка; текущий тег для публикации не используется.
