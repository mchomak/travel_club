## Контекст
Первая локальная сборка backend image остановилась при установке Mako 0.7.3: эта версия использует use_2to3, несовместимый с текущим packaging toolchain. Требование собирать image локально для linux/amd64 остаётся в силе.

## Решение
Считать D01 разрешённым после чистой сборки linux/amd64 без Docker-кэша: она установила Mako 1.4.3, ошибка не повторилась, список зависимостей не менялся.

## Почему
Повторяемая чистая сборка не подтвердила необходимость менять зависимости ради устранения исходного сбоя.

## Последствия
Сборка продолжает использовать текущий набор зависимостей. При воспроизведении ошибки потребуется отдельно закрепить совместимый dependency/build path.
