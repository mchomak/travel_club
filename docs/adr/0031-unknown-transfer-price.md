# ADR 0031: Неизвестная цена трансфера отдельно от нулевой

## Контекст

Автотрансфер создаётся по длительности пути, без тарифа такси.
R37i требует различать отсутствие цены и явно указанную бесплатную поездку.
Подмена неизвестной цены нулём сделала бы неполную смету похожей на завершённую.

## Решение

Для нового автомобильного автотрансфера без цены задавать
`price_pending=true` и `included=false` до явного ввода стоимости.
Показывать «Стоимость не указана» и отмечать итог как неполный.
Явный ввод суммы, включая 0, снимает ожидание и включает элемент в расчёт.
Для пешего перехода задавать известную нулевую цену и `price_pending=false`.
На API запрещать сочетание `price_pending=true` и `included=true`.

## Почему

Нулевое значение само по себе не позволяет отличить неизвестную цену
от подтверждённой бесплатной услуги; отдельный признак сохраняет этот смысл.
Вывод тарифа из длительности отклонён: оценка пути не содержит цены.
Запрет создания до ввода стоимости мешал бы сначала составить календарь.
Существующие финансовые формулы и правила Decimal сохраняются.

## Последствия

Признак ожидания должен сохраняться при повторном открытии и копировании.
Форме, смете и итогам потребуется согласованно показывать неполноту расчёта.
Исключённая неизвестная сумма не делает оставшийся итог полной ценой поездки.
Старые нулевые суммы нельзя автоматически объявлять неизвестными.
Редактор отвечает за ввод цены; сервер контролирует финансовый инвариант.
