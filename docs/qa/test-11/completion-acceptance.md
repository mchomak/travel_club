Проверяется desktop Chromium. Safari/Firefox, реальный GPU memory и FPS на пользовательских устройствах не измерялись. Ошибок JavaScript в capture нет. В manifest сохранены предупреждения ReadPixels/GPU stall, unused CSS preload и Canvas2D readback. Предупреждения об удалённом `PCFSoftShadowMap` после финального rebuild нет; видимая тень и композиция сохранились. [Metadata предыдущего capture](completion-production/pre-shadow-cleanup.json) сохранены отдельно как история до совместимой замены константы. Это не подтверждение производительности на всех GPU.
