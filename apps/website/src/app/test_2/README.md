# Фотографии эксперимента

Каждая глава ссылается на семантический ID в `content.json`. В `photos.json` запись с этим ID содержит `src`, `alt`, `caption`, `ratio` и `objectPosition`. Чтобы заменить любой кадр, добавьте файл в `public/website/assets/photos`, укажите его путь в `src` и обновите описание, подпись и положение. Для отображения нужно указать `sourceUrl`; для стока также сохраните `attribution` и ссылку на лицензию. Для собственных кадров укажите ссылку на подтверждение прав или источник. Отсутствие `src` или `sourceUrl` показывает содержательную заглушку.

Существующие кнопки редактирования привязаны к поддерживаемым слотам и сохраняют замену в отдельную IndexedDB `travel-club-test-2-photos`, не затрагивая главную. Замена через конфигурацию доступна для каждой главы. Стоковые изображения иллюстративны и не выдаются за фотографии поездки.
