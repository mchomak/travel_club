Primary photo pages and the [Pexels License](https://www.pexels.com/license/) were checked on **2026-10-18**. The source names each author and marks the image free to use. The license permits modification and commercial use; no endorsement by the photographers or depicted people is implied. Exact image download URLs, local dimensions, byte sizes and modifications are recorded in `manifest.json`.

The new files were downloaded from Pexels image URLs, converted locally to WebP and sized for a large desktop print composition. CSS controls the final crop. No image-generation or background removal was used. The photograph masks embedded in the CSS are high-resolution alpha masks rasterised from the project's bundled **TC Golos** font, not edited photographs. The actual signature SVG and TC Golos / TC Lora font files are read from the existing brand assets; existing experiments are unchanged.
