# Test 20 font files

These WOFF2 files are local copies of the families offered by the test_20 design settings. They are loaded only on `/test_20` and use `font-display: swap`.

- [Montserrat](https://fonts.google.com/specimen/Montserrat): variable weights 400–700, Latin and Cyrillic subsets.
- [Red Hat Display](https://fonts.google.com/specimen/Red+Hat+Display): variable weights 400–700, Latin subset. Russian characters fall back to TC Golos.
- [Lato](https://fonts.google.com/specimen/Lato): regular and bold, Latin subset. Russian characters fall back to TC Golos.
- [Nunito Sans](https://fonts.google.com/specimen/Nunito+Sans): variable weights 400–700, Latin and Cyrillic subsets.

Each family is distributed under the SIL Open Font License 1.1; the corresponding `*-OFL.txt` files are included here. The font binaries were downloaded from the Google Fonts CSS API and its `fonts.gstatic.com` CDN.
