These local Lato assets are used by the Travel Club design system.

- `lato-regular-latin.woff2` and `lato-bold-latin.woff2` were copied unchanged from the existing `/test_20` assets.
- `lato-cyrillic-regular.ttf`, `lato-cyrillic-medium.ttf`, `lato-cyrillic-semibold.ttf`, and `lato-cyrillic-bold.ttf` are from the official Google Fonts `ofl/lato` family directory and include Cyrillic glyphs.
- `Lato-OFL.txt` contains the SIL Open Font License supplied with the family.

The `Travel Club Lato` CSS family name isolates these files from `/test_20`'s independent experimental typography controls. The font data remains unchanged.
