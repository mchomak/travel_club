# Публичная редакция Travel Club

Основные маршруты — `frontend/src/app/(publication)/{formats,archive,start,thanks,legal,privacy,personal-data}/page.tsx`. Route group не меняет URL. `layout.tsx` использует один `SiteShell`, который создаёт header, skip link, `main#publication-main` и footer. Страницы внутри группы не добавляют собственные main/header/footer. Главная остаётся `/test_5`. Стандартная неизвестная страница — `frontend/src/app/not-found.tsx`, с отдельной обёрткой SiteShell.

## Общая система

Источник истины — неизменяемый `frontend/src/components/design-system/tokens.ts`, экспорт `BASE_TOKENS`. `site-tokens.ts` экспортирует `createSiteVariables(tokens?: PlaygroundTokens): CSSProperties` и переводит цвета, семьи/роли type, spacing, layout и frame ratios в локальные CSS variables. Переменные применены только к `[data-publication-root]`; Playground drafts не читаются и не применяются. `fonts.css` подключает уже существующие self-hosted Golos/Lora из `frontend/public/test/fonts/`.

Primitive цвета, spacing, layout и ratios меняются в `BASE_TOKENS.colors/spacing/layout/frames`; размеры, веса, line height и tracking — в `BASE_TOKENS.typography[role]`. Семьи `--pub-font-sans` и `--pub-font-serif` (включая fallback) задаются в `site-tokens.ts`. Единственный источник alias `--pub-font-editorial` — этот adapter: он выбирает primitive по `BASE_TOKENS.typography.h3.family`. H1/H2/H3 используют общий editorial alias; их собственные размеры и начертания остаются из соответствующих BASE ролей. Поэтому для общей семьи редакционных заголовков менять h3.family, а не h1.family/h2.family. Изменение primitive serif распространяется на все три уровня.

Adapter выдаёт `--pub-type-{role}-{fluid,mobile,family,weight,line-height,tracking}`; `publication.module.css` разрешает semantic `size`. Роли: h1/h2/h3/lead/body/small/meta/caption/button/display-xl/display-l (BASE bodySmall → small, metadata → meta). Размеры в rem, desktop fluid clamp интерполирует mobile390 → desktop1440; до 760px включаются mobile sizes. Adapter использует desktopSize/mobileSize, не Playground responsiveScale. Цветовые aliases `.root`: `--pub-surface` → Cloud, `--pub-text` → Ink, `--pub-accent` → brandBlue, `--pub-border` → line. Metadata не меньше .75rem; H1 до 359px дополнительно ограничен 11vw.

Центральный override для юридических заголовков находится в `publication.module.css`: `--pub-type-legal-title-size` наследует H1, на mobile ограничен `min(var(--pub-type-h1-size), 8.5vw)`. Он применяется к PageIntro перед legalLayout и сохраняет целые длинные слова на 390/320px. Мобильные стрелки legalIndex позиционируются отдельно, оставляя тексту ширину колонки. Остальные semantic overrides менять только в этом CSS или adapter; значения не копировать в CSS отдельных страниц. `page-tokens.css` отсутствует.

## Reusable API

`primitives.tsx`: `EditorialLabel({children})`, `PageIntro({label,title,children?})`, `CTA({href,children,secondary?})`, `EditorialImage({src,alt,caption?,ratio?,priority?})`. Image ratios: landscape/portrait/square/hero из BASE; Next Image fill, object-fit cover, фиксированный размер кадра. `legal-document.tsx`: `LegalNavigation()`, `LegalDocument({title,kind:'privacy'|'personal-data'})`.

`site-shell.tsx`: `SiteShell({children: ReactNode})`; `formats.tsx`: `Formats()`; `archive.tsx`: `Archive({records?: readonly ArchiveRecord[]})`; `start-form.tsx`: `StartForm({initialFormat?: 'route'|'complete'|'group'})`. Архивные записи и тип ArchiveRecord — в `archive-data.ts`: годы группируются из данных, пять текущих записей являются Field Notes, официальных Issues и detail routes пока нет. Formats использует три редакционных разворота с контекстными CTA; Archive — годовые маркеры и разные масштабы кадров. Компоненты страниц используют локальный `editorial-pages.module.css` или `start-form.module.css` для композиции, общую типографику — из publication.

Общие CSS classes: `container`, `h1/h2/h3`, `displayXL/displayL`, `lead/body/small/meta/caption/button`, `muted/accent`, `textLink`, `actions`, `section/rule/columns/prose`, `field/control/fieldLabel/fieldHint/fieldError`, `buttonPrimary/buttonSecondary`. Дополнительные CSS страниц задают только композицию с этими semantic variables/classes. Не импортировать public CSS в RootLayout/globals.css.

## Маршруты и переходы

`/formats` объясняет маршрут, поездку под ключ и поездку в компании; CTA ведут на `/start?format=route|complete|group`. `/archive` показывает поездки друзей до запуска и заканчивается приглашением на `/start`. `/start` выбирает формат из query; неизвестное, повторённое или отсутствующее значение даёт route. Направление, даты, количество людей, бюджет и комментарий необязательны. Контакт проверяется через существующий `components/test/lead.ts`; если количество заполнено, оно должно быть положительным целым. Ошибка фокусирует первое неверное поле. Успешная demo-валидация открывает `/thanks`; введённые данные остаются только в React state до перехода, отправки, localStorage и backend persistence нет.

В `test_5/data.ts`, `editorial-home.tsx` и `field-notes.tsx` обновлены только переходы: навигация, содержание, продуктовые CTA, начало разговора, NEXT ISSUE и ссылки документов. «Форматы» → `/formats`, «Выпуски»/архив → `/archive`, разговор → `/start`, документы → `/legal`. Настоящие якоря `#club`, `#field-notes`, `#next-issue` и другие сохраняются; существующая homepage demo-форма `#story` и Living Issue остаются на месте. Возврат через общий wordmark и notice CTA ведёт на `/test_5`. Неизвестные URL обрабатывает стандартный Next.js `not-found.tsx`, отдельного `/404` route нет.

## Честные placeholders

`/legal` содержит только реальные ссылки на `/privacy` и `/personal-data`; оферта, реквизиты, договор, оплата и возврат отмечены как будущие документы без ссылок. Privacy/personal-data — планы разделов со статусом «Документ находится в подготовке. Не является действующим документом». Утверждённого правового текста и сведений об операторе нет, они не выдуманы. `/thanks` подтверждает завершение демонстрации и отсутствие отправки/сохранения. Фотографии архива иллюстративные, detail routes для Field Notes отсутствуют.
