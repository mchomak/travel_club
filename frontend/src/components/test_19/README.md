# `/test_19` — вертикальная главная Travel Club

Независимая копия `/test_8`, улучшенная редакционными деталями `/test_13`.
Оба исходных маршрута и их компоненты сохранены без изменений.

## Что изменилось

- Обычный документ с нативной прокруткой: убрано журнальное вступление,
  нет камеры, перелистывания, WebGL, фиксации страницы и журнального фрейма.
- Утверждённый логотип из `/test_13` заменяет большой текстовый masthead;
  тот же знак используется в шапке и подвале. Локальная копия SVG окрашена
  в заметный тёмно-синий `#214C78` вместо почти чёрного `#0C1924`.
- `editorial-symbol.tsx` — локальная копия авторской системы `/test_13`:
  сетка 24×24, stroke 1.35, одинаковые окончания линий. Она используется
  для продуктов, переходов, принципов, Field Notes и этапов разговора.
- Travel Design — «от 5 000 ₽», Travel Ready — «от 10 000 ₽»,
  TC Trips — «По согласованию». Пояснения о стоимости услуг сохранены.
- NEXT ISSUE: красный `#B93625`, кремовый `#F5E2A0`, круглый фотокадр;
  NEXT выровнен влево, ISSUE вправо. Одинаковая оптическая ширина строк
  создаёт зеркальные отступы. На планшете и телефоне графика идёт над текстом.
- THAILAND ’26: исходные контуры букв из `/test_13` вынесены в локальные
  PNG-маски, фотография сохраняет бирюзовое море внутри букв. Тёмно-зелёный
  фон, крупный год и редакционная подпись адаптированы к вертикальной секции.
- Сохранены все главы, якоря, `/formats`, `/archive` и `/start?format=…`.
  Выбор формата доступен мышью и клавиатурой; выбранное значение передаётся
  при переходе к разговору. Новых форм отправки и API нет.
- Редактор фотографий сохранён. `photo-slots.ts` — локальный снимок 14
  кадров, без импорта компонентов или данных `/test_8` и `/test_13`.
  IndexedDB `travel-club-test-19-photos` изолирует замены фотографий.
  Фотографии, шрифты и базовые публикационные токены используются совместно
  только для чтения. Фототипографика — постоянная редакционная графика;
  замены через редактор применяются к обычным фотокадрам.
- Композиции desktop/tablet/mobile, видимый keyboard focus и reduced motion.
  Новых зависимостей, переменных окружения и изменений backend нет.
