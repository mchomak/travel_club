# «Между строк» — карманное издание

Изолированный `/test_18`: обложка и четырнадцать портретных листов исходного `test_13`. Каждый лист имеет собственную композицию; высота содержимого естественная, прокрутка — вертикальная прокрутка документа. На широком экране один портретный лист лежит на спокойном фоне. Основной текст 16px, подписи от 12px; изображения не определяют доступность текста и действий.

## Публичные границы

- `pages.tsx`: `PocketPage({ page: number })` — один доступно названный `article[data-pocket-page]` и один `h1[data-reader-heading][tabIndex=-1]`. Нумерация 1-based. Не содержит навигационного состояния.
- `page-data.ts`: `PAGE_COUNT = 15`, `PAGES: readonly {number,title,chapter: number|null}[]`, `CHAPTERS: readonly {label,start,end}[]`. `chapter` — индекс главы от нуля, у обложки `null`.
- `parsePageValues(value: string|string[]|undefined): number` принимает единственную строку `1`…`15`; отсутствие, массив, повторение, пробелы, дробь, экспонента, ведущий ноль или значение вне диапазона возвращают 1.
- `app/test_18/page.tsx` ожидает `searchParams`, отдаёт текущий лист на сервере, содержит noindex metadata. Обычные href переходят на соседние листы, обложку и семь глав; посторонние query, включая повторённые, сохраняются.
- `reader.tsx`: `PocketReader({ initialPage: number, initialQuery?: string })` — прогрессивное чтение. `initialQuery` содержит сериализованные посторонние query для серверных href. Единственное текущее число страницы управляет article, URL, фолио и оглавлением. Native History API сохраняет адреса и Back/Forward без перезагрузки; scroll каждого листа хранится до размонтирования reader. При первом рендере фокус не меняется; переход ставит его на заголовок без потери scroll.

Нижние стрелки и фолио доступны постоянно; на обложке стрелка подписана «Открыть». Фолио открывает печатное оглавление Radix Dialog: семь глав и обложка, текущая глава, focus trap, Escape, возврат к фолио и месту чтения. Без JavaScript работают native href и разворачиваемое noscript оглавление. Footer учитывает safe area; ResizeObserver резервирует его фактическую высоту, в том числе при 200% текста. `viewport-fit=cover` включён без ограничения zoom.

ArrowLeft/ArrowRight работают вне интерактивных элементов, модификаторов, диалога и выделенного текста. Дополнительный touch-свайп начинается внутри листа, дальше 28px от системного края, только одним пальцем, вне ссылок/кнопок и без выделения. Вертикальное намерение отменяет перелистывание; `touch-action: pan-y pinch-zoom` сохраняет native scroll и zoom. Конечная CSS-анимация бумаги занимает 230ms; новый переход доступен сразу, reduced motion убирает движение. Нет canvas/WebGL, capture/decode pipeline, idle-loop или таймера готовности текста.

`pages.module.css` оформляет только новое издание. Цвета/колонтитулы связывают листы, а их ритм различается: охристая обложка, синий горный фотолист, реестр услуг, парные портреты, красная апертура NEXT ISSUE, THAI/LAND из фотографий, тёмный CHINA, контактные отпечатки и бордовые принципы.

Данные и авторские SVG читаются из `../test_13/data` и `../test_13/editorial-symbol`; шрифты — из существующего `public-site/fonts.css`. Старые компоненты, стили и assets не меняются. Фото сохраняют исходные `src`, `alt`, подписи авторства и иллюстративности. THAI/LAND и CHINA используют настоящее начертание TC Golos с `background-clip:text`; тонкий контур оставляет надпись видимой при недоступном фото. Тяжёлые исходные raster mask dataURI не копируются.

## Проверка

Из `frontend/`: `npm.cmd test -- --run src/components/test_18/pages.test.tsx --testTimeout=15000`, `npm.cmd run lint`, `npm.cmd run typecheck`.

Браузерная проверка: `$env:PLAYWRIGHT_BASE_URL='http://127.0.0.1:3118'; npm.cmd exec playwright test e2e/test-18-magazine.spec.ts -- --workers=2 --output=test-results/test18-reader`. Сервер должен уже работать по заданному адресу. Набор проверяет 15 листов/7 глав на 320×700, 390×844, 430×932, 320×568 и 844×390; focus/scroll/history, invalid query, no-JS при недоступных фото, быструю клавиатуру и reduced motion, фактический CDP touch input и реальное увеличение CSS-шрифта 16→32px. Артефакты издания находятся в ignored `frontend/test-results/test18/`; trace при ошибке — в отдельном output, чтобы не удалять screenshots.

Статический тест сопоставляет все 15 листов с реальными `MagazineCover` и соответствующими сторонами `MagazineSpread` по каждому текстовому узлу, уникальным сочетаниям `img src/alt` и всем `href`. Это проверка публичного содержимого, не snapshot внутренней вёрстки. Отдельно проверяется недоверенный query parser.

Фотографии иллюстративные. Настоящие портреты основателей пока отсутствуют: подписанные области не заменяются стоковыми лицами. Цены, условия услуг, статус будущей поездки и оговорка о форме-прототипе сохранены. Размеры текста нового издания заданы в rem, чтобы пользовательское увеличение сохранялось; длинный материал прокручивается по документу. Это портретная редакционная версия с упрощённой физикой листа. Chromium с touch input не заменяет физические iOS/Android: browser chrome, safe area, системные края и реальное пользовательское чтение требуют отдельного испытания. Preview доступен только там, где запущен соответствующий сервер; публикация на VPS в этот этап не входит.
